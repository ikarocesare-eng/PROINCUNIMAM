Este painel está preparado para publicar alterações no seu repositório GitHub. Conclua a conexão inicial no Netlify para habilitar o login.

  1. Conecte o repositório ao Netlify.
  2. Defina GITHUB_REPOSITORY como usuario/repositorio.
  3. Configure o provedor OAuth GitHub no Netlify e faça um novo deploy.
